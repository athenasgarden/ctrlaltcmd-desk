# Interrupt the runaway process

Ctrl+Alt+Cmd is the three-key idea: stop what is thrashing before you add another layer.

Use this when your week is full of tools, chats, and half-started builds, and nothing left the building.

## What thrashing looks like

- You opened a new model to finish work the last model already drafted
- You have three notes titled system prompt and no shipped file
- You can describe the architecture and cannot name who would use it this month
- Yesterday’s output is still in a tab. Today you asked the same question again

If two of those are true, do not start a fourth tool.

## The interrupt (25 minutes)

Close every tab that is not the one object you already have. Write four lines: the object, what done means, the next physical action, everything you will refuse. Do the action until the timer ends.

Leave the other models closed for the rest of the day.

Tomorrow you may open one tool, for that object, for one hour. Not for a new object.
