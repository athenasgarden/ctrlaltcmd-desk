# Signal vs slop

A filter for anything a model just handed you — including this page.

## Keep it if

- You can point to a fact that would make the sentence false
- A specific person could do the next step without asking what you meant
- It uses numbers, dates, file types, or constraints you actually have
- You would defend it out loud without looking back at the chat

## Throw it out if

- It promises a result nobody can verify
- It added a second product while answering a first-product question
- The verbs are unlock / elevate / leverage and nothing happens if you delete them
- It agrees with you in the first line

## The 10-minute pass

Highlight unverifiable statistics. Cut invented objects. Read the rest out loud and rewrite the stumbles in your voice. Write one next action. If you cannot, the output was atmosphere.
