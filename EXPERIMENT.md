# One-sitting experiment

A digital experiment is not a startup. It is a question you can answer before dinner.

Good questions end. Bad ones need a new domain and a logo.

## Constraints

90 minutes. One artifact. No new subscription. Publish or discard at the end. Drafts that live a month are attic, not experiments.

Minute 0–10: write the question and the artifact name.
10–70: make only that artifact.
70–80: run the signal filter.
80–90: put it where a stranger can see it, or delete it.

After: one paragraph — what you thought would happen, what happened, what you will not try again. That paragraph is the analysis.
