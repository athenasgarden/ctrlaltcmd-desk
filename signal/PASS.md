## Keep a sentence if

- [ ] I can name a fact that would make it false
- [ ] A specific person could do the next step without asking what I meant
- [ ] It uses numbers, dates, file types, or constraints I actually have
- [ ] I would defend it out loud without looking back at the chat

## Cut a sentence if

- [ ] It promises a result nobody here can verify
- [ ] It invented a second product while answering the first question
- [ ] The verbs are unlock / elevate / leverage and nothing happens if I delete them
- [ ] It agreed with me in the first line
